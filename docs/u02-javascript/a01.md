# Actividades de JavaScript

> **Entrega:** un único repositorio de GitHub llamado `dw-u02-actividades`. Cada actividad se resolverá en su propia carpeta: `a01`, `a02`, `a03`, etc. Salvo que se indique lo contrario, cada carpeta contendrá el archivo `.js` correspondiente. Se valorará especialmente que puedas explicar y modificar tu código.

## Actividad 1: Primer contacto con JavaScript

🔴⚫⚫⚫⚫

Crea `a01/app.js`. Declara una constante con tu nombre y muestra mediante `alert` tres mensajes: `Hola mundo`, tu nombre y el tipo de `alert` obtenido con `typeof`. Añade además un `console.log` con un mensaje de bienvenida.

**Conceptos:** `const`, `alert`, `console.log`, `typeof`.

## Actividad 2: ¿Qué tipo soy?

🔴⚫⚫⚫⚫

Crea `a02/types.js`. Define al menos un valor de cada tipo trabajado en clase: `number`, `bigint`, `string`, `boolean`, `null`, `undefined`, `symbol` y `object`. Muestra cada valor y el resultado de `typeof`.

Comprueba también `typeof alert`.

**Conceptos:** tipos de datos y `typeof`.

## Actividad 3: Interpolando mensajes

🔴🔴⚫⚫⚫

Crea `a03/templates.js`. Predice primero mediante comentarios la salida de estas expresiones y después compruébala ejecutándolas:

```js
let name = "Ilya";
alert(`Hola ${1}`);
alert(`Hola ${"name"}`);
alert(`Hola ${name}`);
```

Añade después un mensaje propio que use una plantilla literal e incluya como mínimo dos variables y una operación aritmética dentro de `${...}`.

**Conceptos:** strings, template literals e interpolación.

## Actividad 4: Calculando

🔴🔴🔴⚫⚫

Crea `a04/calc.js`. Solicita dos números y muestra suma, resta, multiplicación, división y resto. Indica además cuál es mayor, o si son iguales, y determina para cada número entero si es par o impar utilizando `%`.

No realices una división cuando el segundo valor sea `0` y evita continuar si alguna entrada no es numérica.

**Conceptos:** operadores aritméticos, comparaciones y `if`.

## Actividad 5: Clasificador de números

🔴🔴🔴⚫⚫

Crea `a05/sign.js`. Pide un número al usuario y muestra:

* `1` si es positivo;
* `-1` si es negativo;
* `0` si es cero.

Rechaza una entrada que no pueda convertirse en un número válido. Resuelve primero el problema con `if / else if / else`. Como ampliación, calcula el resultado con un operador ternario.

**Conceptos:** condiciones, conversión y operador ternario.

## Actividad 6: Control de acceso

🔴🔴🔴🔴⚫

Crea `a06/access.js`. Solicita nombre y edad. El programa deberá:

1. convertir la edad a número;
2. aceptar únicamente una edad numérica válida y no negativa;
3. indicar si la persona puede acceder cuando tenga al menos 18 años;
4. utilizar `"Anónimo"` cuando no se haya introducido un nombre útil;
5. mostrar los tipos de los valores recibidos antes y después de la conversión.

Investiga la diferencia entre utilizar `||` y `??` para el nombre. Incluye al menos **cinco casos de prueba** como comentarios al final del archivo, indicando entrada y salida esperada.

**Conceptos:** integración de variables, tipos, conversiones, comparaciones, condiciones y valores por defecto.

## Actividad 7: Precio final

🔴🔴🔴🔴⚫

Crea `a07/price.js`. Solicita el precio de un artículo y un porcentaje de IVA. Convierte ambos valores correctamente y calcula el importe del IVA y el precio total.

El programa debe impedir cálculos con entradas no numéricas o valores negativos y mostrar el resultado con dos decimales.

**Conceptos:** entrada de datos, conversión, operaciones, condiciones y validación básica.

## Actividad 8: Inicio de sesión

🔴🔴🔴🔴⚫

Crea `a08/login.js`. El sistema tiene las siguientes credenciales almacenadas:

```js
const VALID_USER = "admin";
const VALID_PASSWORD = "1234";
```

Solicita el usuario y la contraseña mediante `prompt` y muestra el resultado que corresponda:

* `"Acceso concedido"` si ambas credenciales son correctas.
* `"Usuario incorrecto"` si el usuario no coincide.
* `"Contraseña incorrecta"` si el usuario es correcto, pero la contraseña no.
* `"Debes introducir usuario y contraseña"` si falta cualquiera de los dos datos.

La contraseña debe compararse como **texto**, no como número. Comprueba primero que se hayan introducido ambos datos; después valida el usuario y, a continuación, la contraseña.

Una vez resuelta esta parte, añade el bloqueo de la cuenta:

```js
const isBlocked = false;
```

Aunque las credenciales sean correctas, si `isBlocked` es `true` se debe denegar el acceso y mostrar `"Acceso denegado: cuenta bloqueada"`.

**Conceptos:** `prompt`, constantes, comparaciones, condiciones y orden de validación.

## Actividad 9: Reserva de hotel

🔴🔴🔴🔴⚫

Crea `a09/hotel.js`. El hotel aplica estas reglas:

* Habitación estándar (`"standard"`): **60 € por noche**.
* Habitación superior (`"superior"`): **90 € por noche**.
* Las personas menores de 18 años no pueden realizar una reserva.
* Las estancias de **7 noches o más** tienen un descuento del **10 %**.

Solicita el nombre del cliente, la edad, el número de noches y el tipo de habitación. El programa deberá:

1. Convertir y validar la edad y el número de noches. La edad debe ser un número válido no negativo y las noches, un entero positivo.
2. Rechazar la reserva si la persona es menor de 18 años.
3. Aceptar únicamente los tipos `"standard"` y `"superior"`.
4. Calcular y mostrar el precio inicial, el importe del descuento y el precio final.
5. Mostrar `"Cliente"` si no se ha introducido un nombre útil.

Si los datos no son válidos o no se cumplen las condiciones de reserva, informa del motivo y no calcules el precio.

**Conceptos:** conversión, validación, condiciones, operaciones y valores por defecto.

## Actividad 10: Simulador de compra online

🔴🔴🔴🔴🔴

Crea `a10/shop.js`. Simula una compra solicitando el nombre del cliente, el precio del producto, la cantidad de unidades y un código de descuento.

Los códigos disponibles son:

| Código | Descuento |
| --- | ---: |
| `JS10` | 10 % |
| `JS20` | 20 % |
| Cualquier otro | Sin descuento |

El programa deberá:

1. Convertir y validar el precio y la cantidad. El precio no puede ser negativo y la cantidad debe ser un entero mayor o igual que `1`.
2. Calcular el subtotal (`precio × cantidad`).
3. Determinar el porcentaje de descuento según el código e indicar el ahorro.
4. Calcular el precio final.
5. Mostrar `"Invitado"` si no se ha introducido un nombre útil.
6. Mostrar un resumen con el cliente, precio unitario, cantidad, subtotal, porcentaje de descuento, ahorro y total.

Muestra los importes con dos decimales. Por ejemplo, para el nombre `Javier`, un precio de `25`, una cantidad de `3` y el código `JS10`, el resumen incluirá:

```text
Cliente: Javier
Precio: 25,00 €
Cantidad: 3
Subtotal: 75,00 €
Descuento: 10 %
Ahorro: 7,50 €
TOTAL: 67,50 €
```

**Conceptos:** conversión, validación, operaciones, condiciones, porcentajes y formato de salida.
