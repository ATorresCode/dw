# Actividades de JavaScript: métodos de arrays

Estas actividades se realizarán en clase de forma colaborativa. En cada caso, indica qué método o métodos utilizarías y explica brevemente por qué son adecuados para resolver el problema.

> No es necesario programar la solución completa. El objetivo es identificar correctamente el método más apropiado y comprender su funcionamiento.

---

## Actividad 1: Carrito de la compra

Disponemos de un array de objetos `{ nombre, precio }`.

Queremos obtener el importe total de todos los productos del carrito.

<details>
<summary>Solución</summary>

reduce()

Recorre el array acumulando la suma de los precios.

```js
productos.reduce((total, producto) => total + producto.precio, 0);
```

</details>

---

## Actividad 2: Nuevo alumno

Tenemos un array con los nombres de todos los alumnos de una clase.

Queremos añadir un nuevo alumno al final de la lista.

<details>
<summary>Solución</summary>

push()

Añade uno o varios elementos al final del array.

```js

```

</details>

## Actividad 3: Comprobar acceso

Tenemos un array de usuarios con `{ nombre, rol }`.

Queremos saber si existe algún usuario con rol `"admin"`.

<details>
<summary>Solución</summary>

some()

Devuelve `true` si al menos un elemento cumple la condición.

```js
usuarios.some(usuario => usuario.rol === "admin");
```

</details>
