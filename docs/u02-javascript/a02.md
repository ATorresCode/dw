# Actividades de JavaScript: bucles, funciones, objetos y arrays

> **Entrega:** continúa en el repositorio `dw-u02-actividades`. Cada actividad se resolverá en su propia carpeta (`a11`, `a12`, etc.) y contendrá, como mínimo, el archivo `.js` indicado. Se valorará especialmente que puedas **explicar, probar y modificar tu código**.
>
> Las actividades están agrupadas por tema y ordenadas de menor a mayor dificultad dentro de cada bloque. La dificultad se representa con 🔴 y ⚫.

## Bloque 1. Bucles y funciones

### Actividad 11: Cuenta atrás controlada

🔴⚫⚫⚫⚫

Crea `a11/countdown.js`. Solicita un número entero positivo y muestra por consola una cuenta atrás desde ese número hasta `0`, ambos incluidos.

El programa deberá:

1. convertir y validar la entrada;
2. rechazar valores que no sean enteros positivos;
3. realizar la cuenta atrás con un bucle `while`;
4. mostrar al terminar `¡Despegue!`.

Como ampliación, resuelve el mismo problema con `for` y compara ambas versiones mediante un comentario.

**Conceptos:** `while`, `for`, conversión, validación y contadores.

### Actividad 12: Pares, impares y múltiplos

🔴🔴⚫⚫⚫

Crea `a12/range.js`. Solicita un entero `n` mayor que `0` y recorre los números desde `1` hasta `n`.

Muestra cada número e indica si es par o impar. Al finalizar, muestra también:

- cuántos números pares hay;
- cuántos impares;
- la suma de los múltiplos de `3`.

La repetición principal debe resolverse con `for`. Evita repetir cálculos innecesarios dentro del bucle.

**Conceptos:** `for`, `%`, acumuladores, contadores y condiciones.

### Actividad 13: Clasificador de meses con `switch`

🔴🔴⚫⚫⚫

Crea `a13/seasons.js`. Implementa una función `getSeason(month)` que reciba el nombre de un mes y devuelva `"Invierno"`, `"Primavera"`, `"Verano"` u `"Otoño"`.

Utiliza obligatoriamente `switch` agrupando los meses que comparten estación. La función no debe utilizar `alert` internamente: debe **devolver** el resultado con `return`.

Solicita el mes fuera de la función y muestra el resultado. Si el texto no identifica un mes válido, muestra un mensaje adecuado.

**Conceptos:** `switch`, agrupación de `case`, funciones, parámetros y `return`.

### Actividad 14: Entrada hasta `STOP`

🔴🔴🔴⚫⚫

Crea `a14/input.js` e implementa `readNumbers()`. Solicita números repetidamente mediante `prompt` hasta que ocurra una de estas situaciones:

- se pulsa Cancelar;
- se introduce una cadena vacía;
- se escribe `STOP`.

El valor `0` debe aceptarse como un número válido. Si se introduce otro texto no numérico, informa del error y vuelve a solicitar un valor sin finalizar el programa.

La función debe devolver la suma de los números válidos y la cantidad de números introducidos. Puedes decidir cómo representar ambos resultados, pero deberás explicar tu elección mediante un comentario.

**Conceptos:** bucles indefinidos, `break`, validación, acumuladores, funciones y `return`.

### Actividad 15: Detector de números primos

🔴🔴🔴🔴⚫

Crea `a15/primes.js`. Implementa:

```js
function isPrime(number) {
  // ...
}
```

La función devolverá `true` únicamente si `number` es primo. Después crea `showPrimes(limit)`, que muestre todos los números primos comprendidos entre `2` y `limit`.

Requisitos:

1. no programes una lista fija de primos;
2. reutiliza `isPrime()` desde `showPrimes()`;
3. detén la comprobación de divisores en cuanto sepas que un número no es primo;
4. rechaza un límite que no sea un entero mayor o igual que `2`.

**Conceptos:** funciones reutilizables, bucles anidados, `break`, `%`, booleanos y validación.

### Actividad 16: Menú de operaciones reutilizable

🔴🔴🔴🔴🔴

Crea `a16/function-menu.js`. Diseña las funciones `sum(a, b)`, `subtract(a, b)`, `multiply(a, b)` y `divide(a, b)`. Después implementa:

```js
function calculate(a, b, operation) {
  // ...
}
```

`operation` será una **función callback**. El programa deberá solicitar dos números y una operación, seleccionar la función adecuada y mostrar el resultado.

Requisitos:

- controla la división entre cero;
- no dupliques las fórmulas dentro de `calculate`;
- utiliza al menos una función flecha;
- permite repetir operaciones hasta que el usuario decida terminar;
- incluye al final cinco casos de prueba comentados.

**Conceptos:** funciones como valores, callbacks, funciones flecha, bucles, validación y separación de responsabilidades.

## Bloque 2. Objetos

### Actividad 17: Ficha de un producto

🔴⚫⚫⚫⚫

Crea `a17/product.js`. Define un objeto `product` con las propiedades `name`, `price` y `stock`.

Después:

1. muestra las tres propiedades mediante notación de punto;
2. añade `category` después de crear el objeto;
3. modifica el stock;
4. elimina `category`;
5. comprueba con `in` si existe `stock`;
6. recorre y muestra sus propiedades con `for...in`.

**Conceptos:** objetos literales, propiedades, `delete`, `in` y `for...in`.

### Actividad 18: Inventario y copia independiente

🔴🔴⚫⚫⚫

Crea `a18/inventory.js`. Define un objeto `inventory` cuyas claves sean productos y cuyos valores indiquen las unidades disponibles, por ejemplo:

```js
const inventory = {
  monitor: 8,
  keyboard: 15,
  mouse: 20,
};
```

Implementa `countTotal(obj)` utilizando `for...in` para devolver el número total de unidades.

Después crea `branchInventory` mediante una copia superficial con `Object.assign` o spread, cambia su cantidad de monitores a `0` y demuestra mediante `console.log` que el inventario original no ha cambiado.

Añade un comentario que explique por qué una simple asignación como `const branchInventory = inventory` no serviría para este objetivo.

**Conceptos:** `for...in`, funciones, referencias y clonación superficial.

### Actividad 19: Agenda de contactos

🔴🔴🔴⚫⚫

Crea `a19/contacts.js`. Parte de un objeto que represente un contacto y que pueda contener:

```js
{
  name: "Marta",
  email: "marta@example.com",
  address: {
    city: "Castellón",
    postalCode: "12001"
  }
}
```

Implementa `showContact(contact)` para mostrar nombre, correo y ciudad. Algunos contactos podrán no tener `address` o `email`.

Requisitos:

- utiliza `?.` para acceder de forma segura a la ciudad;
- utiliza `??` para mostrar `"No disponible"` cuando falte un dato;
- prueba la función con al menos tres objetos diferentes, incluyendo uno sin dirección.

**Conceptos:** objetos anidados, encadenamiento opcional, `??` y funciones.

### Actividad 20: Cuenta bancaria como objeto

🔴🔴🔴🔴⚫

Crea `a20/account.js`. Define un objeto `account` con `owner`, `balance` y estos métodos:

- `deposit(amount)`: añade una cantidad válida al saldo;
- `withdraw(amount)`: descuenta una cantidad únicamente si hay saldo suficiente;
- `showBalance()`: muestra titular y saldo con dos decimales.

Los métodos deben utilizar `this`. No permitas cantidades negativas, cero o valores no numéricos.

Haz una secuencia de al menos cinco operaciones e indica mediante comentarios el saldo esperado después de cada una.

**Conceptos:** métodos, `this`, validación, estado de un objeto y formato numérico.

### Actividad 21: Constructor de perfiles

🔴🔴🔴🔴⚫

Crea `a21/users.js` y una función constructora `UserProfile(name, role)`.

Cada objeto creado tendrá:

- `name` y `role` recibidos como argumentos;
- `active` con valor inicial `true`;
- `showInfo()`, que devuelva un texto con los datos del usuario;
- `deactivate()`, que cambie `active` a `false`.

Crea con `new` al menos tres perfiles con roles diferentes. Desactiva uno y muestra la información de todos.

Como ampliación, añade un método `hasRole(role)` que devuelva un booleano.

**Conceptos:** funciones constructoras, `new`, métodos, `this` y booleanos.

### Actividad 22: Catálogo con copia de seguridad

🔴🔴🔴🔴🔴

Crea `a22/catalog.js`. Define un objeto que contenga información anidada:

```js
const catalog = {
  store: "TechShop",
  settings: {
    currency: "EUR",
    showStock: true,
  },
  featured: {
    name: "Monitor",
    price: 199.99,
  },
};
```

Realiza dos copias:

1. una superficial mediante spread;
2. una profunda mediante `structuredClone`.

Modifica en cada copia `settings.currency` y `featured.price`. Muestra después los tres objetos y explica mediante comentarios por qué una de las copias puede compartir cambios anidados con el original y la otra no.

Finalmente, implementa `updateFeatured(catalog, name, price)` y úsala sobre la copia profunda, no sobre el original.

**Conceptos:** referencias, objetos anidados, copia superficial, `structuredClone` y funciones.

## Bloque 3. Arrays

3. elimina la última con `pop` y muéstrala;

5. muestra el número de tareas restantes;
6. recórrelas con `for...of`.

**Conceptos:** arrays, `length`, `push`, `pop`, `shift`, `unshift` y `for...of`.

### Actividad 24: Suma de números introducidos

🔴🔴⚫⚫⚫

La entrada termina al pulsar Cancelar, dejar la cadena vacía o introducir un valor no numérico. El `0` es válido y no debe detener la entrada.

Al terminar muestra:

- el array introducido;
- la cantidad de números;
- su suma;

Si no se introdujo ningún número, evita dividir entre cero.

### Actividad 25: Buscar y filtrar productos

🔴🔴🔴⚫⚫

Crea `a25/products.js` a partir de:

const products = [

  { id: 2, name: "Keyboard", price: 35, stock: 0 },
  { id: 3, name: "Mouse", price: 20, stock: 12 },

5. comprueba con `every` si todos los precios son positivos.

**Conceptos:** arrays de objetos, `find`, `filter`, `map`, `some` y `every`.

### Actividad 27: Estadísticas de clase

### Actividad 28: Calculadora extensible

🔴🔴🔴🔴🔴

Crea `a28/calculator.js`. Implementa una función constructora `Calculator` que permita evaluar expresiones sencillas con el formato exacto:

```text
NUMERO operador NUMERO
```

Inicialmente debe reconocer `+` y `-`:

```js
const calculator = new Calculator();
console.log(calculator.calculate("3 + 7")); // 10
```

Añade un método `addMethod(name, fn)` que permita incorporar operaciones nuevas:

```js
calculator.addMethod("*", (a, b) => a * b);
calculator.addMethod("/", (a, b) => a / b);
calculator.addMethod("**", (a, b) => a ** b);
```

Requisitos:

- utiliza `split` para separar la expresión;
- almacena las operaciones en un objeto o estructura equivalente;
- rechaza expresiones mal formadas y operadores desconocidos;
- controla la división entre cero;
- prueba como mínimo `+`, `-`, `*`, `/` y `**`;
- indica mediante comentarios dos entradas erróneas y el comportamiento esperado.

**Conceptos:** `split`, arrays, objetos, funciones como valores, callbacks, constructor, métodos y validación.

## Indicaciones de entrega y revisión

Antes de dar una actividad por terminada:

- usa nombres de variables y funciones descriptivos;
- evita `var` salvo que el ejercicio pida estudiar código antiguo;
- evita duplicar código que pueda extraerse a una función;
- comprueba entradas problemáticas, no solo el caso ideal;
- incluye comentarios cuando se pidan predicciones o casos de prueba;
- asegúrate de poder explicar qué hace cada parte de tu solución.

### Comprobación en clase

El profesor podrá pedir una modificación breve sobre cualquiera de las actividades, por ejemplo cambiar una condición, añadir un dato, reutilizar una función o explicar qué ocurre con una referencia. La finalidad es comprobar la comprensión del código entregado.
